# KNN Decision Boundary Visualizer

An interactive Streamlit app to visualize how K-Nearest Neighbors behaves on
different 2D datasets and hyperparameters.

## Features
- Real-time KNN decision boundary visualization
- Multiple datasets (Classification, Circles, Blobs, Moons)
- Adjustable neighbors, distance metric, and weighting
- Accuracy and confusion matrix
- Train/Test visualization toggle

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Matplotlib

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
